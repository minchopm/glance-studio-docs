# Glance Studio — operating procedures

Use these procedures as task-oriented reference. They describe public capabilities and verification steps, not private implementation. UI labels can vary by version.

## Procedure 1: Test reading pace before final rendering

### Before you begin

Use a short fictional script with both short and long messages.

### Steps

1. Preview without pausing.

2. Check that each message stays readable before the next arrives.

3. Adjust delays for longer text and voiceover.

4. Check captions, media and camera motion at the busiest moment.

5. Render a short sample and review it on a phone-sized display.

### Expected result

The story can be followed at normal playback speed.

### If the result differs

Some site demonstrations are development previews; use features actually present in the installed build.

## Procedure 2: Prepare a fictional product conversation

### Before you begin

Use invented participants and permission-cleared media.

### Steps

1. Write the question and a supported product answer.

2. Remove unsupported promises and fabricated testimonials.

3. Set participants and message order.

4. Preview narration and media timing.

5. Label fictional content appropriately when publishing.

### Expected result

The video communicates a product use case without masquerading as a real customer exchange.

### If the result differs

Local rendering does not grant permission to use another person's avatar, music or private messages.

## Report a repeatable problem

Record app/version, device/OS, selected mode, input conditions and the smallest failing step. Distinguish expected behavior from the observed result. Use synthetic examples and omit credentials or private records.
